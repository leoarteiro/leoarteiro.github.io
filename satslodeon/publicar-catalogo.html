Publicar o catálogo, o perfil e o site no Nostr

Publica o catalog.json desta página como um evento assinado pela chave do projeto. O app e o site leem o catálogo dos relays e só aceitam eventos dessa chave. Cada publicação substitui a anterior. A assinatura é feita pela extensão Nostr (NIP-07) ou pelo Amber no celular (NIP-46); a chave nunca passa por esta página.

    No Amber: toque em + (ou “Conectar”) e leia este código com a câmera. Escolha a chave do projeto e aprove.

    Abrir no Amber (se esta página estiver aberta no próprio celular)

    3. Assinar e publicar

    Uma assinatura só; o mesmo evento vai para todos os relays. Com o Amber, aprove a assinatura no celular.

      4. Perfil do projeto

      Nome, descrição, imagens e Lightning Address que os apps Nostr mostram para a chave do projeto (arquivo profile.json). O avatar e a capa precisam estar no Blossom antes (página de envio).

          5. Site no nsite

          Escolha a pasta web do projeto. Os arquivos vão para o Blossom (só os que faltam) e uma lista assinada pela chave do projeto diz aos gateways quais arquivos formam o site. A pasta dev/ fica de fora.
